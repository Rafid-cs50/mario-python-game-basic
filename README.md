# 🍄 Super Mario Platformer (Python & Pygame)

A classic 2D retro platformer built in Python using Pygame. Features 10 unique levels, power-up mushrooms, distinct enemy types, moving platforms, and built-in sound effects.

---

## 🎮 Features

- **10 Campaign Levels:** Progressively challenging levels with moving platforms and pit hazards.
- **Power-Ups:** Collect Super Mushrooms to double in size and gain an extra hit shield.
- **Enemy Variety:** 
  - 🟤 **Goombas:** Basic patrolling enemies (stompable).
  - 🟢 **Koopas:** Fast-moving enemies (stompable).
  - 🔴 **Spikies:** Sharp enemies (cannot be stomped!).
- **Synthesized Audio:** Built-in sound generator for jumps, coins, power-ups, and stomps (no external assets required).

---

## 🕹️ Controls

| Action | Key |
| :--- | :--- |
| **Move Left** | `A` or `Left Arrow` |
| **Move Right** | `D` or `Right Arrow` |
| **Jump** | `Spacebar` / `W` / `Up Arrow` |
| **Restart Game** | `R` (on Game Over screen) |
